final check results. Required checks cover full Windows/Linux Python 3.11/3.14
suites (including licensing and publication-safety regressions), Ruff, strict
mypy, supply chain/sdist, base and optional installations, portable plugins,
stdio MCP, self-digest, B1/menu ranking, real acquisition quota and CodeQL.

The resumed repair updates two stale host-test scenarios: deterministic seed
planning and optional semantic planning are exercised separately, and the
registration-preservation fixture supplies the required explicit host limits.
Configuration refusal and semantic-planner assertions remain enforced.

No mandatory parser/vector/model dependency is added. Existing nutrient keys,
licence modes, origin ceilings, ledger authority and publication guards remain.
New source/seed/evidence fields are additive; raw literals and explicit scoring
overrides remain available. Cached evidence still requires identity/integrity
validation; a changed producer or invalid snapshot requires regeneration.
