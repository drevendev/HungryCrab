## Independent qualification

The [first actual study](../experiments/release-069-discovery-qualification.md)
completed twelve metered trials and six separate reviews. Both arms confirmed
zero unique actionable changes; one baseline held source proposal remains
disputed. All reviews found inadequate investigation coverage. This fails the
release usefulness gate, not evidence that useful changes do not exist.
[#540](https://github.com/drevendev/HungryCrab/issues/540) records the blocker.

Product corrections add real pinned path/declaration navigation, qualified
Python names and literal declaration queries, explicit continuation ranges,
and hash-bound source/notice pages. The raw JSON remains authoritative.

[The second completed comparison](../experiments/release-069-followup-qualification.md)
sealed a source-unseen third pool before both arms and completed twelve bounded
attempts with six fresh arm-masked reviews. The intermediate second pool produced
only a calibration, not a paired study. The third-pool comparison tested C9/d390:
baseline 152,370 actual tokens, candidate 133,137, reviewers 90,372. Only eight
distinct donors were admitted across all trials; all reviewers found coverage
inadequate. The resolved baseline design became BeautifulRepo #223, not a new
candidate finding or human acceptance. Candidate gain and precision were not
demonstrated. Original results and failed prototype costs remain intact.

The frozen host's guessed paths, excessive evidence compression, unassessed
replacements and incorrect reviewed flags contributed to failure. CLI refusals
remain correct. Later corrections, outside both measured results:
