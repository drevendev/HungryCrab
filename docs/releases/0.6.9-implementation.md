## Independent qualification

The [first actual study](../experiments/release-069-discovery-qualification.md)
completed twelve metered trials and six separate reviews. Both arms confirmed
zero unique actionable changes; one baseline held source proposal remains
disputed. All reviews found inadequate investigation coverage. This fails the
release usefulness gate, not evidence that useful changes do not exist.
[#540](https://github.com/drevendev/HungryCrab/issues/540) records the blocker.

Product correction adds real pinned path/declaration navigation, qualified
Python names and literal declaration queries, explicit continuation ranges,
and hash-bound source/notice pages without wholesale output loss. The raw JSON
remains authoritative. Existing resource/path/origin/licence guards remain.

[The new preflight](0.6.9-qualification-preflight.json) prepares a different thirty
with actual provider/default pins. It is not sealed: freeze the corrected code,
new receiving/pending contexts and improved host before either arm. Fixed 2 GiB
hosted acquisition is available and was used in study one. Bounded existing
Codex account quota is authorised by the requested checks; no new purchase or
additional permission is pending. Trial usage counts cached input. Currency is
unknown and unavailable usage stays null.
