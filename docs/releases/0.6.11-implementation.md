## First P0 slice: acquisition lifecycle

PR #687 registers accepted client sockets before handler dispatch and owns a
separate stopped registry per acquisition scope. Late upstream connections cannot
register or acknowledge CONNECT after scope teardown. Cleanup closes sockets
without waiting for the byte-reader accounting lock. Reuse keeps old handlers
bound to the old stopped scope. Download accounting is preserved; an in-progress
DNS/connect call retains its existing cancellation limits.

The owned relay test listener now always shuts down/joins before socket close,
including when a test assertion raises. This repairs an unsafe fixture unwind.
The original managed-local Windows exception `0xc0000008` has not been conclusively
reproduced or attributed; do not report the historical crash diagnosed merely
because a hosted suite passes.

An Actions lifecycle matrix covers Ubuntu/Windows Python 3.11/3.14. Owned
event/socket-pair regressions cover partial CONNECT, normal/cancelled teardown,
late upstream completion, scope reuse, blocked-reader cancellation and fixture
assertion unwinding. Early revisions passed all 23 lifecycle tests in each leg;
hosted Ruff/format/mypy findings were corrected in subsequent source commits.
Those earlier successes do not certify a later head. Final checks must bind the
actual PR SHA and retain original failed runs. No local test/lint/type/build ran.

No independent reviewer has yet approved this implementation. PR #687 remains
