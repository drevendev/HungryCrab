# 0.6.0 release record

0.6.0 Everywhere was released on 2026-10-22 as a limited stable analysis release. The owner approved
this scope on 2026-10-21 and confirmed it on
[#293](https://github.com/drevendev/HungryCrab/pull/293) on 2026-10-22. The deferred criteria
below remain open; a missing result is never recorded as a pass.

## Scope

- **Stable:** deterministic, human-supervised analysis: the CLI, scoped stdio MCP (the optional
  `[mcp]` extra), portable skills and offline HTML reports.
- **Experimental:** PR publication, Scheduled Crab work autonomy and Taste Memory
  learning/usefulness claims.
- **Postponed:** the optional tree-sitter syntax index (owner decision, 2026-10-22). The runtime
  dependency is PyYAML alone; `code` stays a deferred category.

## How it landed

1. [#291](https://github.com/drevendev/HungryCrab/pull/291): the 0.3-0.5 integration and its
   safety work, with the review repairs listed in its squash commit. It superseded #235, #237,
   #240, #241, #244, #246, #253, #259, #270, #284 and #288.
2. [#292](https://github.com/drevendev/HungryCrab/pull/292): Everywhere, with the MCP scope
   repairs (no UNC or device paths, no repository above the roots, `--check` from any
   directory).
3. The release/reopen pair, rebase-merged, with `v0.6.0` on the release commit.

Every landing passed the required upstream checks on Windows and Linux with Python 3.11 and
3.14. B1 is unchanged: recall 10/10, noise 19/29.

## Installation

Install from the tag:
`uv tool install "hungry-crab[mcp] @ git+https://github.com/drevendev/HungryCrab@v0.6.0"`. The
package is not published to PyPI, where the `hungry-crab` name is not registered by this
project. Claude Code offers the plugin update because its version changed with this release.
