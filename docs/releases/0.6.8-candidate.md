## Delivered behavior

- **#481–#483:** receiving-context-bound behavior hypotheses feed donor discovery
  even when structural traits are complete. Distinct facets precede synonyms;
  supported runtimes rotate and a language-neutral pool is explicit. Four requests
  remain the default, sixteen the maximum. Query/source provenance, failed attempts
  and deferred work remain visible. Search results still require pinned source and
  license verification.
- **#207:** legacy summary JSON keys remain compatible, while sniff/digest name
  their concrete representative maws. GPL-3.0-only summary compatibility does not
  imply GPL-2.0-only compatibility.
- **#258:** anchored/flow YAML can receive a config-hash-bound manual scoring edit
  description. Automatic unsafe rewriting stays refused; duplicate/ambiguous keys
  cannot produce a patch.
- **#328:** MCP menu accepts deep analysis, keeps depth-specific snapshots, and
  identifies which side lost visibility or failed producer/integrity checks.
- **#347/#348:** provider reconciliation survives later stops/failures. Recovery
  records interrupted expired or clock-invalid leases once, including while
  paused, without spending a new phase or discarding a live lease.
- **#497–#500:** review regressions are repaired before the release commit.
  Planned search rechecks live receiving inputs before provider requests;
  partial reports retain bounded, sanitized causes and recovery hints. Manual
  scoring patches validate fresh YAML with scalar types preserved. Loop status
  remains readable during writer activity and reports `writer_busy` without
  mutating a busy writer's lease.

## Validation and limits

The final PR and native check runs hold the exact tested head, full suite results,
lint/types, installations and artifact validation. Missing/pending/skipped checks
are not successful validation. All new probes use original synthetic receiving
data; no donor program or test is executed.

[PR #496](https://github.com/drevendev/HungryCrab/pull/496) records the reviewed
implementation and all four repaired regressions. Master CI passed before tagging;
[tag CI](https://github.com/drevendev/HungryCrab/actions/runs/40731019580) passed
before GitHub publication triggered the trusted PyPI workflow. The release/reopen
trees were verified against the tested candidate and rebuilt 0.6.8 artifacts.

These changes improve query planning and recovery correctness. They do not establish
a measured semantic-discovery gain or later maintainer uptake. The new code/test
search backend, source packets, active replanning, new providers and held-out live
agent trial remain outside this patch.
