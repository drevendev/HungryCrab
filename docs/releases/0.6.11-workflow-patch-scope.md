unsupported budget certification or misleading verification/review completion.

clean local Codex session can review without acquiring the prey.

interactive remote investigation, complete local delivery and measured practical
efficiency remain 0.7 acceptance.

### T9 supported subset

Modified matrices admit one to eight nonempty axis names, literal lists of unique
strings (empty lists allowed), no expressions or include modifier, and at most
256 Cartesian assignments. Exclusions are literal nonempty dictionaries containing
only known axis names/string values. Remove each matching assignment once;
duplicate/nonmatching exclusions do not distort the count.

Repeated axis values, unsupported shapes/types, expressions, includes or a larger
product retain inspectable raw/base facts and an unknown surviving count. Test
partial/full exclusions, empty axes, zero survivors and ordinary no-modifier /
`fail_fast` controls. No workflow execution or new dependency.

### A1–A4 first handoff

Support one public GitHub prey and one owner-selected maw at accessible full
commits. The default acquisition worker is GitHub-hosted Linux. Python 3.11/3.14
and Windows/Linux package/consumer checks remain required. Do not promise Windows
volume provisioning without its actual prerequisites. Preserve existing modes;
private-source expansion is outside this first remote profile.

Accept an inert request with unique identity, purpose, immutable pair/tool context,
receiving policy and finite acquisition/output/time limits. Return complete
admissible evidence or a typed failure/partial/hold. There is no arbitrary command,
model prompt or publication credential. The first handoff may advertise source
continuation as unsupported; 0.7 must implement the actual remote continuation.

Local Codex judges nutrient/evidence/licence data and may manage the maw's own Git
state and authorized publication through host tools. It does not run Crab analysis
or a local benchmark host. Full COPY/REIMPLEMENT delivery stays held wherever its
independent authority checks cannot yet work without local prey acquisition.

## Required controls

| Control | Expected observation |
| --- | --- |
| Named pair without usage capability | Supervised route works with unknown inference cost; no repository search merely to enter the route. |
| Strict route without qualified usage | Refusal before lease/model/provider effect; no positive budget certification. |
| Unadmitted operation, receipt replay or late charge | No unauthorized dispatch/advance; original operation/cost settles once. |
| Wrong-ref or post-start duplicate basis | Unresolved or later-superseded; frozen history stays intact. |
| Successful helper but failed actual consumer | User-visible verification fails; ordinary control remains valid. |
| Missing or source-mismatched requested reviewer | Independent-review stage remains incomplete. |
| Partial CONNECT, late connect or scope reuse | No late registration/forwarding; original quotas/accounting remain intact. |
| Expired/corrupt/oversized/wrong-run artifact | Refusal/hold; no silent catch or automatic rerun. |
| Git pack, repository tree or unsafe archive member | Refusal before local materialization. |
| Valid fixture evidence, absent local prey cache | Bounded review and local dry-run succeed, preserving rights holds. |
| Nutrient provenance through export, review and final draft | Exact source commit/file/line links remain clickable and match recorded evidence. A homepage, mutable branch, wrong range or missing source cannot replace provenance. |
| Failed/cancelled miner or job | No success bundle; retain diagnostics, actual coverage and costs. |

## Compatibility

stable maw-relative nutrient keys and existing ledger meanings. New transport
identity/evidence fields are additive and versioned. Existing meals/receipts stay
readable with honest legacy/unknown authority; never retroactively certify them.
Any required key/schema migration needs an explicit migration design and tests.
Do not change default local CLI behavior merely to introduce the remote profile.
