# 0.6.9 independent discovery qualification: first study

Status: **failed release gate**. All six separate reviews found investigation
coverage inadequate. The implementation remains a development candidate.
This does not demonstrate that useful changes do not exist.

The [machine-readable record](release-069-discovery-qualification.json) preserves
the original seal, immutable pins, twelve completed trials, six separate reviews,
disagreements, actual usage and artifact hashes. The three
`release-069-host-*.py.txt` files preserve the executed host as inert audit data.

All twelve completed staged trials stayed within equal resource caps. Separate
reviews consumed another 142,262 actual tokens. Currency is unknown; no
efficiency claim is made. Failed/interrupted prototypes are recorded separately;
incomplete actual usage remains unknown.

One baseline source-supported held proposal concerned optional wikilinks in
BeautifulRepo. Reviewers disagreed about novelty; neither confirmed it actionable.
It must remain in the report. An empty approved set has undefined precision,
not 100%. The candidate demonstrated neither overall gain nor gains in two maws.

The investigation failed in product and host: guessed paths, irrelevant initial
windows, large outputs dropped wholesale, incomplete pending-source access,
no executed receiving probes, and conservative admission stranding usable token
budget. Some admitted donors received no completed decision. Two repeats cannot
establish a general model-performance claim or absence of useful changes.

The pool excluded the historical shared thirty, but failed host pilots had seen
some facts before the final restart. No pilot judgment reached either final arm;
nevertheless this was not pristine held-out evidence. Arm metadata was masked
from reviewers, though evidence shape may suggest an arm.

[#540](https://github.com/drevendev/HungryCrab/issues/540) tracks the blocker and
acceptance. Corrections include real pinned paths and declarations, explicit
continuation ranges, bounded evidence pages with raw-artifact identities,
exact pending-file reads and receiving verification. The next study uses a
different thirty-repository pool, sealed before either arm. This failure remains
part of release evidence. No donor program ran, nutrient was published,
receiving code changed, or merge, tag or release occurred.
